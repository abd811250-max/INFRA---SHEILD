# Data

## Road Network Dataset

The project currently uses cleaned OpenStreetMap road data for:

**Location:** Lucknow, Uttar Pradesh

**Records:** 181,305

**Geometry:** LineString

**CRS:** EPSG:4326

## Dataset Status

The cleaned GeoJSON dataset is stored locally during development and is not
currently included in this GitHub repository because of its size.

The repository contains the scripts and database documentation required for
the road-data import process.
